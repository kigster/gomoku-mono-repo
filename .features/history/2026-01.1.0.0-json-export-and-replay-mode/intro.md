# Gomoku 1.0.0 — the first "we're proud of this" release

Version 1.0 is a statement: the terminal game is complete and stable. The big new
abilities are the power to save a finished game to a structured file (JSON) and
to replay it move by move afterward — handy for studying what happened or sharing
a game. The board's saved form uses clean Unicode symbols so it's readable.

Alongside that: more AI improvements, a fix to choosing which side you play, and
a real documentation set. Nothing about how you play changes, but the game is now
something you'd confidently hand to a stranger.
