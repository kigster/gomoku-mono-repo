# Gomoku 3.0.0 — the web app grows up

With the web app working, this release makes it feel polished and professional.
The interface is substantially reworked — cleaner modals, an ambient animated
background, refined settings and rules screens. The leaderboard is fixed so each
player appears once (no duplicate entries). And the deployment story is fleshed
out with real options and documentation for running it in the cloud.

It's less "brand-new abilities" and more "take the 2.0 web app and make it look
and run like something you'd ship to the public."
