# Gomoku 0.3.1 — a grown-up build system

Software needs a way to turn source code into a running program. Until now that
was a hand-written Makefile. This release adds CMake — an industry-standard build
system that figures out how to compile the project across different computers and
tools, and plays nicely with test frameworks and IDEs.

For players, nothing changes. For anyone building or contributing to the game,
it's a big step toward "just works everywhere." The in-game help screen also got
a refresh.
