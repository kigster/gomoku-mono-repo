# Gomoku 0.5.0 — variety, speed, and tidy code

Two improvements for players and one for developers. For players: the AI gets a
dash of controlled randomness, so it no longer plays the exact same game every
time from the same position — more variety, less predictability — and its
move-generation is optimized to run faster. For developers: a `make format`
command that auto-formats the C code to a consistent style, so the codebase stays
clean without anyone fussing over spacing by hand.
